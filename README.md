# 🎨 Melanin Canvas | Black Heritage Art & Coloring Studio

An interactive digital art studio celebrating Black American culture, history, musical genius, afro-futurism, and community joy.

## ✨ Key Features & Modes

### 1. 🖌️ Classic Coloring Studio
- **Dual Canvas Engine**: Real-time bitmap drawing with vector path boundaries.
- **Smart Bucket Fill**: High-performance 4-way stack flood fill with outline threshold protection.
- **Dynamic Brushes & Textures**:
  - Smooth Acrylic Brush (soft anti-aliased strokes)
  - Wax Crayon (authentic jittered wax grain)
  - Translucent Ink Marker
  - Afro Glow (neon afrofuturism starlight aura)
  - Glitter & Sparkle Stamp (radiant gold, bronze & cowrie sparkles)
  - Precision Eraser & Eyedropper color sampler
- **"Stay Inside The Lines" Protection**: Automatically ensures your colors stay underneath the crisp black line art overlay.
- **Multi-Level Undo & Redo** with snapshot cache.
- **Pan & Zoom** (60% to 250%).

### 2. 🔢 Paint by Numbers
- High-fidelity segmented artworks with numbered zone badges.
- **Live Progress Badges**: Dynamic counters (`3/8 completed`) for each color tier.
- **Interactive Region Radar**: Selecting a color number causes matching uncolored regions to pulse gently.
- **Smart Hint Tool**: Automatically locates and spotlights unfilled regions for the active color.
- **Full Victory Celebration**: Triumphant brass fanfare, confetti explosion, and seamless number fade-out upon 100% completion.

### 3. ⚪ Connect the Dots
- High-precision numerical dot puzzles tracing iconic Black cultural symbols (The Golden Saxophone of Harlem, The Crown Silhouette, The Underground Railroad Freedom Lantern).
- **Ascending Kalimba / Marimba Chimes**: Synthesizes pentatonic musical scale notes as each sequential dot is connected.
- **Auto-Assist Mode**: Dynamic automated connector for younger artists or demonstrations.
- **Instant Color Conversion**: Once completed, reveals the master illustration with a 1-click button to jump straight into the Coloring Studio to color it!

### 4. 🪄 AI & Custom Photo Studio
- **Cultural Prompt Presets**: Curated generation prompts honoring Afrofuturism, Crown Hair Joy, Jazz Legends, HBCU Pride, and Sacred Akan Geometry.
- **Gemini API Integration**: Secure local storage of user API keys.
- **Client-Side Computer Vision Converter**: Upload *any* personal photo, family portrait, or historical image to convert it into a crisp black-and-white coloring sheet using real-time Sobel edge detection, Gaussian blurring, and adaptive thresholding!

### 5. 🎶 Soulful Audio Synthesizer
- Web Audio API procedural synthesis:
  - African Kalimba / Marimba notes
  - Triad chord bucket fill chimes
  - ASMR soft brush strokes
  - Procedural Neo-Soul & Lofi ambient jazz chords (Fmaj9, Em7, Dm9, Cmaj7) for a calming, meditative coloring experience without needing any external MP3 files.

### 6. 🖨️ Cultural Gallery & Printables
- Save artworks with timestamped previews in local gallery.
- Export high-resolution PNGs.
- **Printable 8.5" x 11" Coloring Sheets**: Direct browser print formatting for physical crayons and colored pencils.

## 🚀 Getting Started

```bash
cd melanin-canvas
npm install
npm run dev
```

Visit `http://localhost:5173/` in your browser.
